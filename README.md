# Expense Tracker

A small React + Vite app for tracking money in and money out, in Kenyan shillings (KSh).

## Features
- Add income and expenses with a description, amount, category and date
- Balance, total money in and total money out at a glance
- Spending breakdown by category
- Filter transactions: All, Money in, Money out
- Data is saved in your browser (localStorage), so it survives a refresh

## Run it
```bash
npm install
npm run dev
```

## Built with
React 19, Vite 7, plain CSS
